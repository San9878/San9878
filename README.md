
## 🐉 Hi, I'm Santiago Hernández Chávez

I'm an Artificial Intelligence Engineering student at Universidad Panamericana and an incoming Research Intern at **King Abdullah University of Science and Technology (KAUST)**.

My main interests are **Computer Vision, Deep Learning, 3D Reconstruction, and Spatial AI**. I enjoy implementing research architectures, experimenting with neural networks, and understanding how models behave beyond controlled environments.

Currently, I'm focused on transformer-based visual geometry, monocular depth estimation, camera pose estimation, and efficient 3D reconstruction.

### 🌟 featured projects

- 🔬 **3D endoscopic reconstruction | VGGT, VGGT-TTT & VGGT3**  
  implementing and evaluating transformer-based architectures for monocular 3D reconstruction. working with depth estimation, camera poses, multi-view geometry, and point cloud reconstruction using `pytorch` and `cuda`. experimenting with the `c3vd` and `simcol3d` datasets, analyzing geometric consistency, reconstruction errors, and inference efficiency.

- 🐄 **CowVision | cattle detection & computer vision**  
  developing a modular computer vision system for cattle monitoring using `python`, `pytorch`, and `rt-detr`. currently focused on object detection in images and videos, with an extensible architecture designed for future tracking, individual re-identification, and behavioral analysis.

- 🩺 **medical image classification | EfficientNetB3**  
  trained and fine-tuned an image classification model using the `kvasir-v2` dataset, implementing mixup and label smoothing to improve model generalization.

- 🦾 **neural inverse kinematics | 6-DOF robotic arm**  
  developed a neural network in `matlab` to estimate inverse kinematics for a 6-DOF robotic manipulator, reducing trajectory tracking error through model optimization.

- 🧃 **AI feedback collector | FastAPI & Supabase**  
  built a backend for collecting and evaluating AI-generated responses. integrates `fastapi`, `pydantic`, and `supabase` for RESTful APIs, input validation, secure data storage, and human feedback workflows.

- 🛵 **vehicle speed analysis | YOLO & BST**  
  implemented vision-based vehicle detection and speed estimation using `yolo`, combined with binary search trees for structured data management.
